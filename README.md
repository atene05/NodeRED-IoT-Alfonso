## Funcionamiento del proyecto

Este proyecto fue desarrollado en Node-RED y utiliza servicios REST para consultar información sobre el consumo energético y la ubicación de un laboratorio.

Incluye dos flujos principales:

- Servidor REST: recibe solicitudes HTTP GET y genera respuestas JSON.
- Cliente REST: realiza consultas y presenta los resultados en un dashboard.
